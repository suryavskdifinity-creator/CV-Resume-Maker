# CVora by Suraj — AI Resume Studio

Free AI resume builder with 120+ professional templates, live preview, and PDF export.

**Author:** Suraj Vishwakarma  
**Contact:** suraj.infotechsolution@gmail.com  
**Ads:** Google AdSense `ca-pub-7504961737515196`

## Run

```bash
npm install
npm run dev
```

## Features

- 120+ templates (Classic, ATS, Corporate, Modern, Creative…)
- Step wizard builder + live preview
- PDF download (ad modal → download)
- Google Ads on Home, Templates, Tools, Editor, PDF flow
- Local save (browser)

## Env

Copy `.env.example` to `.env`. Optional slot IDs when you create AdSense units.
